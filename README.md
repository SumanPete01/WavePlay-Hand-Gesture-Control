# 🖐️ WavePlay - Hand Gesture Control System

Real-time touch-free computer interaction using hand gestures with **92% accuracy** and **<100ms latency**.

## 🚀 Features
- **6+ Gesture Recognition**: Fist, Open Palm, Point, Pinch, V-Sign, Cursor
- **Multi-Application Control**: Media, Browsing, Desktop Navigation
- **Low Latency**: <100ms response time
- **High Accuracy**: 92% gesture recognition rate
- **No Hardware Required**: Works with standard webcam (60 FPS)

## 🎮 Gesture Mapping
| Gesture | Action | Use Case |
|---------|--------|----------|
| ✊ **Fist** | Move Cursor | Navigation |
| ✋ **Open Palm** | Space (Play/Pause) | Media Control |
| 👆 **Point** | Next/Previous | Media Browsing |
| 🤏 **Pinch (Left)** | Volume Control | Audio Adjustment |
| 🤏 **Pinch (Right)** | Zoom In/Out | Document Viewing |
| 🤟 **V-Sign** | Switch Desktop | Workspace Management |
| 👍 **Cursor** | Mouse Click | Selection |

## 🛠️ Installation

### Prerequisites
- Python 3.8+
- Webcam

### Setup
```bash
# Clone repository
git clone https://github.com/SumanPete01/WavePlay-Hand-Gesture-Control.git
cd WavePlay-Hand-Gesture-Control

# Install dependencies
pip install -r requirements.txt

# Run application

python waveplay.py
